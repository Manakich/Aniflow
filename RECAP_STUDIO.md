# AniFlow Recap Studio — руководство

## Назначение

Один путь производства: **ссылка на мангу → готовые кадры AniFlow → цельный русский пересказ → пронумерованные изображения → беззвучное видео → комплект публикации YouTube**.

## 1. Загрузка

Вставьте ссылку на поддерживаемый scraper-ом сайт. Выберите одну главу или диапазон глав. AniFlow скачивает страницы в папку проекта.

## 2. Автоматическая подготовка кадров

После загрузки нажмите одну кнопку «Подготовить кадры и продолжить». Внутри выполняется штатная последовательность AniFlow: Stitch → Detect 1 / Crop 1 → Stitch 2 → Detect 2 → Crop 2 → извлечение OCR-контекста.

Recap Studio не запускает второй независимый детектор поверх Crop 2, не обрезает готовые изображения повторно и не фильтрует их заново. Внутренние этапы используют smart-resume: если кадры или OCR уже сохранены, они переиспользуются. Старые Stitch/Detect/Crop больше не являются отдельными пользовательскими экранами.

## 3. OCR-контекст

Штатный OCR извлекает текст из пузырей. Он нужен сценаристу как справочный контекст, а не как готовый текст для озвучки. Исправьте очевидные ошибки распознавания, если они влияют на смысл.

## 4. Сценарий

Сценарист создаёт один цельный русский пересказ. Целевой объём по умолчанию — около 5 000 слов; его можно изменить. Длинный текст пишется последовательными текстовыми частями с сохранением хронологии и непрерывности.

Встроенный профиль основан на общих приёмах предоставленных примеров: подробное изложение причин и последствий; живой разговорный темп; уместная ирония; понятное объяснение рангов, навыков, способностей и правил мира. Сценарист не копирует точные фразы/шутки конкурентов, не переводит реплики дословно и не выдумывает события ради объёма. После генерации сценарий можно отредактировать.

## 5. Пронумерованные кадры и silent MP4

После сохранения сценария нажмите создание видео. Программа копирует готовые Crop 2-кадры в `numbered_panels`, нумерует их по порядку чтения, сохраняет `script.txt` и `manifest.json`, затем собирает один MP4 с плавными эффектами движения. Для отдельного использования сценарий также можно скачать прямо из интерфейса.

Длительность считается по фактическому тексту:

`duration_seconds = word_count × 0.72`

- 5 000 слов = 3 600 секунд = 01:00:00.
- 10 000 слов = 7 200 секунд = 02:00:00.

При изменении сценария длительность пересчитается при следующем экспорте. Все кадры идут последовательно на протяжении всей длительности. В видео нет аудиопотока: TTS, выбора голоса, музыки и звуковых эффектов в приложении нет.

## 6. YouTube-пакет

Финальный этап создаёт:
- три разных названия по реальным событиям сценария;
- три превью 16:9 с крупной русской надписью;
- описание;
- закреплённый комментарий.

Стиль встроен заранее по переданным примерам. Дополнительные скриншоты для отдельного выпуска можно загрузить, но они необязательны. Пакет добавляется в папку экспорта: `thumbnails/`, `title_options.txt`, `description.txt`, `pinned_comment.txt` и `youtube_package.json`. При выборе названия выбранный вариант тоже сохраняется в пакет. Для генерации изображений нужен `OPENAI_API_KEY` в локальном `.env`; по умолчанию используется GPT Image 2.5 Sunburst. Не сохраняйте ключ в GitHub.

## Установка на Windows

```powershell
git clone -b feat/full-recap-studio https://github.com/Manakich/Aniflow.git
cd Aniflow
setup.bat
```

Для уже клонированного проекта:

```powershell
.\venv\Scripts\Activate.ps1
copy .env.example .env
python app.py
```

Настройте LLM backend AniFlow (Ollama или совместимый API/9router), добавьте OpenAI key для превью и откройте `http://localhost:8080`.

## Проверки и следующий реальный тест

GitHub Actions проверяет компиляцию Python, unit-тесты сценария, нумерации, silent MP4, превью и JavaScript. Перед регулярной работой нужен реальный прогон на Windows: небольшая глава, проверка фактов/имён в пересказе, порядка кадров и воспроизведения MP4. Список доступных сайтов определяется текущим scraper-ом; target word count — ориентир для LLM, а длительность видео считается по фактическому числу слов.
