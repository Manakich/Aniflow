# Manga Recap — Secret Voicer Connector

Расширение соединяет локальный Python-проект с уже открытой вкладкой Secret Voicer в обычном профиле Яндекс Браузера. Вход через Telegram остаётся в браузере пользователя. Пароли, коды Telegram и cookies не считываются.

## Установка

1. В Яндекс Браузере открой `browser://extensions`.
2. Удали старую версию «Manga Recap — Secret Voicer Connector», если она уже установлена.
3. Включи режим разработчика и нажми «Загрузить распакованное расширение».
4. Выбери папку `automation/extension` из репозитория.
5. Закрепи значок расширения на панели браузера.

В версии 0.2 используется фиксированный публичный ключ расширения, поэтому у тебя и друга будет одинаковый ID. Это позволяет локальному мосту принимать запросы только от этого расширения. Приватные ключи и пользовательские данные в репозиторий не входят.

## Запуск автоматической озвучки

Из корня репозитория в PowerShell запусти:

```powershell
python automation\\secret_voicer_bridge.py automation\\test_script.txt --name first_auto_test
```

После сообщения «Локальный мост Manga Recap запущен»:

1. Оставь окно PowerShell открытым.
2. Убедись, что в Яндекс Браузере открыта авторизованная вкладка `https://secretvoicer.com/app/`.
3. Нажми значок расширения на вкладке Secret Voicer.
4. Нажми «Запустить задание из Python».
5. Откроется отдельная вкладка прогресса. Не закрывай её и вкладку Secret Voicer до завершения скачивания.

Расширение вставит текст, запомнит адреса уже существующих MP3, нажмёт «Озвучить», дождётся новой уникальной ссылки и скачает файл в `Downloads\\MangaRecapAutomation`. Python скопирует готовый MP3 в `automation\\outputs`.

## Локальная безопасность

- Python слушает только `127.0.0.1`, не сетевой интерфейс компьютера.
- CORS разрешён только фиксированному ID этого расширения.
- Локальный мост принимает задания и результат только в рамках одного запущенного процесса.
- В браузере используется текущая сессия Secret Voicer; сессионные данные не копируются и не отправляются в Python.
