# Manga Recap — Secret Voicer Connector

Расширение связывает локальный Python-проект с открытой вкладкой Secret Voicer. Оно использует текущую сессию Яндекс Браузера: каждый пользователь сам входит через Telegram. Пароли, Telegram-коды и cookies не экспортируются.

## Установка

1. В Яндекс Браузере открой `browser://extensions`.
2. Удали предыдущую версию расширения, если она уже установлена.
3. Включи режим разработчика и выбери «Загрузить распакованное расширение».
4. Укажи эту папку `automation/extension`.
5. Закрепи расширение на панели браузера.

В версии 0.2 в манифест добавлен открытый ключ, который закрепляет одинаковый ID расширения на компьютерах владельца и друга. Не удаляй и не изменяй поле `key` в `manifest.json`.

## Автоматическая озвучка

1. Открой Secret Voicer и войди через Telegram.
2. Выбери нужный голос и режим озвучки.
3. Из корня репозитория запусти в PowerShell:

```powershell
python automation\\secret_voicer_bridge.py automation\\test_script.txt --name first_auto_test
```

4. Оставь Python-терминал открытым.
5. На вкладке Secret Voicer нажми значок расширения → «Запустить задание из Python».
6. Дождись завершения во вновь открывшейся вкладке прогресса.

Результат появится в `automation/outputs`. Расширение сначала запоминает существующие MP3, затем ждёт новый уникальный адрес, чтобы не скачать старую запись из истории.

## Что делает расширение

- Получает сценарий от локального Python-моста.
- Вставляет его в `#text-input`.
- Нажимает `#submit-btn`.
- Ждёт появления новой ссылки `.audio-download-btn`.
- Скачивает новый MP3 через API загрузок браузера.
- Передаёт путь к скачанному файлу локальному Python-процессу.

Расширение имеет доступ только к сайту Secret Voicer и локальному адресу `127.0.0.1`. Локальный мост слушает только loopback и принимает запросы лишь от ID этого расширения.
