# Secret Voicer Connector (диагностика интерфейса)

Первый этап интеграции Manga Recap Automation. Расширение работает с уже открытой вкладкой Secret Voicer в обычном профиле браузера, поэтому вход через Telegram остаётся в том же профиле и не требует передачи cookies в Python.

## Установка в Яндекс Браузер

1. Распакуй/открой папку `automation/extension` из репозитория.
2. Перейди на `browser://extensions`.
3. Если доступен режим разработчика и кнопка «Загрузить распакованное расширение», включи режим и выбери папку `automation/extension`.
4. Если в твоей сборке Яндекс Браузера нет загрузки распакованного расширения, не включай экспериментальные флаги и не устанавливай сторонние сборки: напиши об этом. Подготовим пакет CRX3 для штатной установки через `browser://tune`.

## Проверка

1. Открой `https://secretvoicer.com/app/` в обычном Яндекс Браузере.
2. Войди через Telegram так, как делаешь обычно.
3. Нажми значок расширения и кнопку «Проверить страницу».
4. Просмотри JSON и отправь его для настройки следующих шагов.

Расширение собирает URL, заголовок страницы и описания видимых интерактивных элементов (кнопки, поля, селекторы). Оно намеренно не читает cookies, пароли, local storage и текущие значения текстовых полей. Перед отправкой всё равно проверь содержимое отчёта.

На этом этапе расширение ничего не вводит, не нажимает кнопки генерации и не скачивает аудио. Это диагностический этап, чтобы не угадывать селекторы интерфейса.
