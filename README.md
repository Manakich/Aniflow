## Что делает программа

Это однорежимная версия AniFlow: на главном экране оставлен только Full Recap Studio.

1. Вставьте ссылку на поддерживаемый сайт и выберите главу или диапазон глав.
2. Нажмите одну кнопку подготовки: AniFlow автоматически выполнит штатные внутренние этапы (Stitch → Detect → Crop 2 → OCR). Если Crop 2/OCR уже были сделаны, smart-resume использует сохранённые данные. Дополнительного детектирования и повторной обрезки поверх готовых изображений нет.
3. По готовым кадрам и OCR-контексту программа пишет один цельный оригинальный русский пересказ. Это не перевод реплик и не набор подписей к картинкам.
4. Проверьте и отредактируйте сценарий.
5. Готовые Crop 2-кадры копируются в отдельную папку и нумеруются по порядку чтения.
6. Кадры объединяются в беззвучный MP4. Длительность считается по фактическому числу слов: **0,72 секунды на слово**. 5 000 слов ≈ 1 час; 10 000 слов ≈ 2 часа.
7. Генерируются три превью, три названия, описание и закреплённый комментарий.

## Стиль сценария

Встроенный профиль основан на общих приёмах из предоставленных примеров: подробная хронология, разговорный темп, редкая ирония, понятное объяснение систем/способностей и последствий. Точные формулировки, шутки и фирменные фразы конкурентов не копируются; ошибки OCR не имитируются.

## Видеоряд и файлы

- Используются уже вырезанные изображения Crop 2; исходники не изменяются.
- Экспорт создаёт копии с последовательными именами `000001.jpg/png`, `000002.jpg/png` и т. д.
- На кадрах есть плавное движение.
- В MP4 нет аудиодорожки, TTS, голоса, фоновой музыки или звуковых эффектов.
- В папке экспорта сохраняются `script.txt`, `manifest.json`, пронумерованные кадры, видео, три превью, варианты названий, описание и закреплённый комментарий.

## Упаковка YouTube

Встроенные стили названий и превью настроены заранее. Скриншоты для конкретного выпуска можно приложить дополнительно, но это необязательно. Для трёх превью нужен OpenAI Images API: ключ хранится только в локальном `.env`, не коммитьте его в git.

## Запуск на Windows

```powershell
git clone -b feat/full-recap-studio https://github.com/Manakich/Aniflow.git
cd Aniflow
setup.bat
```

Создайте локальный `.env` на основе `.env.example`, добавьте `OPENAI_API_KEY` для превью и настройте LLM backend (Ollama или совместимый API/9router). Затем выполните:

```powershell
python app.py
```

Откройте `http://localhost:8080`.

## Проверки и ограничения

GitHub Actions проверяет компиляцию Python, unit-тесты сценария/экспорта/превью и синтаксис JavaScript. Это не заменяет реальный прогон на Windows с настоящей ссылкой и API-ключами. Длительность всегда рассчитывается по фактическому количеству слов после редактирования сценария.
